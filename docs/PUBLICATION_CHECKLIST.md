# Publication Checklist

Before making the case-study repository public:

- [ ] Confirm you have the right to publish the Gym Manager name, branding, and derived screenshots.
- [ ] Confirm all nine images are approved for public use.
- [ ] Review Member Profile for personal phone number / identifiable information.
- [ ] Review staff names, usernames, IDs, membership codes, timestamps, and financial-looking values.
- [ ] Keep the source implementation private.
- [ ] Keep current status as development / integration / release hardening unless newer evidence changes it.
- [ ] Do not claim production customers, revenue, reduced churn, time savings, or uptime without evidence.
- [ ] Do not convert “325 test files” into “325 passing tests.”
- [ ] Re-run current verification before updating the audit metrics.
- [ ] Avoid publishing unresolved vulnerability details.

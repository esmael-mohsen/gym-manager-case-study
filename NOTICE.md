# Gym Manager Desktop — Public Case Study Notice

This repository is a public engineering case study for a private commercial-oriented Windows application.

## Source code

The production / commercial implementation is not included.

## Visuals

The repository intentionally uses only the nine visuals selected for this case study:

1. Dashboard
2. Members Management
3. Subscription Packages
4. Prospects & Leads
5. Financial Operations
6. Attendance
7. Reports & Analytics
8. Users & Security
9. Member Profile

The visuals are presentation frames derived from the current product UI. Visible values should be treated as demo / UAT data unless independently verified.

## Privacy review

Before public publication, manually review all visible:
- names,
- phone numbers,
- membership codes,
- timestamps,
- usernames,
- financial-looking values,
- identifiers.

Remove or replace anything that should not be public.
